# Remote plugin for Cursor

This directory contains the Cursor-specific manifest for the `remote-for-ai` plugin.

## Install

Search for **Remote** in `Cursor Settings > Plugins`, or add manually by pointing Cursor at this repository.

For local development:

```bash
ln -s /path/to/remote-for-ai ~/.cursor/plugins/local/remote
```

## Files

- [plugin.json](plugin.json) — plugin manifest with `displayName`, logo, and metadata.
- [marketplace.json](marketplace.json) — single-plugin marketplace descriptor.
